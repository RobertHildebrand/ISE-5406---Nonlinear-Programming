— Chapter Two —

The chain rule, applied with vigor

Forward

Information flows left→right. Each layer takes the previous activations, multiplies by a weight matrix, adds a bias, and squashes the result. The output ŷ is a prediction.

ŷ = σ(W₂·σ(W₁·x + b₁) + b₂)

Backward

The error ℒ = ½(ŷ − y)² flows right→left. The chain rule tells us how each weight contributed to that error — and therefore how to nudge it.

∂ℒ/∂W via chain rule, layer by layer

Below is the same network, now trained on a target — the function y = sin(πx₁) · cos(πx₂). Press Train and watch the loss curve descend. Each step, the network samples a point, computes its error, and propagates gradients backward to update the weights.
